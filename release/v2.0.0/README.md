# VRChat Organizer 2.0.0 Release Assets

This directory is the local staging area for GitHub release assets. Build
scripts replace its generated contents on each release build:

- `VRChatOrganizer-2.0.0-x86_64.AppImage` - Linux x86_64 AppImage
- `VRChatOrganizer-2.0.0-windows-x86_64.exe` - Windows x86_64 CLI executable
- `SHA256SUMS` - checksums for the generated artifacts

Generated binaries and checksums are intentionally ignored by Git. Upload the
files from this directory to the GitHub release matching the application
version.
